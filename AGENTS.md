# Agent Instructions

## Codebase Navigation & Knowledge Graph (`graphify`)

This repository maintains a structural knowledge graph in `graphify-out/` generated by **Graphify**. You **MUST** consult `graphify-out/` and use `graphify` tools before broadly searching (`grep`, `find`, `glob`) or reading raw source files.

### 1. Mandatory Session Start & Orientation

- **Always read `graphify-out/GRAPH_REPORT.md` first** at the beginning of a session or whenever you need architectural orientation, subsystem boundaries ("communities"), or high-connectivity "God nodes".
- If `graphify-out/wiki/index.md` exists, navigate it alongside `GRAPH_REPORT.md` instead of scanning raw directories.
- If `graphify-out/` is missing or empty, initialize it before exploring the codebase:
  ```bash
  graphify update .
  ```
